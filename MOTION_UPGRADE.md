# Optional motion upgrade

The approved identity, portrait composition, project copy and dated evidence are preserved. Added short claim/source/boundary traces, an explicitly illustrative approval workflow, and an optional geometry/audio settings panel.

The blocking loader, scrambled identity, custom cursor overlay and GPU-heavy WebGL loop are replaced by immediate canonical content, a native pointer and a static CSS field. Motion off and reduced motion retain readable content. Collapsed project bodies are inert while scripting is active; project content is exposed without scripting.

Audio is off by default, has volume/mute controls and stops when the document is hidden. The supplied Pink Soldiers recording is included for opt-in playback. It is not represented as original or royalty-free music.

The authoring references were MotionSites' free skill, Bang Motion, and GEOMETRIC, reviewed for scope and licensing; no third-party runtime, starter code or media was imported. References: https://github.com/Motionsites-AI/claude-skill/blob/main/LICENSE ; https://github.com/bangtutorial/bang-motion/blob/main/LICENSE ; https://geometric-art.com/manual .

Local validation: 47 Chromium browser assertions across desktop/mobile, reduced-motion, no-script and script-failure states; individual screenshot inspection; JavaScript syntax checks; a deterministic lifecycle harness with 40 rapid toggles. These are scoped implementation checks, not a WCAG certification, security certification, physical-device test or evidence of conversion/traction uplift.

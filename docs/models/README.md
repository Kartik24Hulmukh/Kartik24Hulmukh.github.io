The archive preview images state **Commercial Use Prohibited**, for personal projects or other non-commercial purposes only. A separate standalone license was not present. These files are not represented as MIT, public-domain, or cleared for commercial use. No franchise endorsement is implied.

The three model JSON files contain quantized, gzip-packed geometry and embedded downsampled WebP textures. Poster JSON files contain model-derived static fallback images. The source archive, FBX/Blend files and full-resolution maps are not published. The source manifest records source hashes, conversion settings and observed licensing evidence. Its `conversion` field names the offline conversion process, not an asset loaded by this site.

Software renderer: Three.js 0.187.0 and its bundled fflate decoder. See repository `licenses/three-MIT.txt` and `licenses/fflate-MIT.txt`. The software licenses do not apply to the character artwork.
